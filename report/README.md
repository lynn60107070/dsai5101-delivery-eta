# Report

IEEE two-column conference format (`IEEEtran` class), 4–6 pages excluding references. `main.tex` pulls in
one `.tex` file per section; each file opens with comments on what the rubric's top band needs and which
proposal-feedback point (FB1–FB4) it must answer.

## How we write it: in this repo, like the code

Overleaf collaboration costs money, so **the repo is the working copy** and Lynn's Overleaf project only
makes the PDF.

1. Edit **only your own section files** (table below), on your own branch.
2. Open a PR into `main`. Lynn compile-checks it, merges it, and copies it into the Overleaf project.
3. To **preview** your section while writing: zip this `report/` folder → overleaf.com (free account) →
   New Project → Upload Project. That private copy is just for viewing; don't edit there.

| File | Section | Owner |
|---|---|---|
| `abstract.tex`, `intro.tex` | Abstract, Introduction | Lynn |
| `related.tex` | Related Work | Sumaiya |
| `data.tex` | Data & Exploratory Analysis | Sumaiya |
| `method.tex` | Methodology | Lynn |
| `results.tex` | Results & Discussion (Sumaiya and Lynn add their subsections by PR too) | Mahmoud |
| `conclusion.tex` | Conclusion (limitations, ethics, future work) | Lynn |
| `main.tex`, `tables/` | Assembly; `tables/` is generated by `python -m experiments.final` | Lynn |

- **References:** add your entries to `refs.bib` in your PR (T1: two scholarly sources each by CP2, each
  with a two-line comment on how it relates to our work). Cite them with `\cite{key}`.
- **Figures:** export to `figures/eda/` or `figures/results/` as PDF; `main.tex` finds them via
  `\graphicspath`. When previewing, upload the figure files with the zip.
